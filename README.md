# Aurevia

**Brass and time, frozen in motion.**

A scroll-driven cinematic experience around a bronze sculpture. Real-time three.js model, animated liquid-metal shader background, drifting sparks, and character-level text reveals choreographed to scroll.

## Tech Stack

- Next.js
- TypeScript
- Three.js
- GLSL Shaders
- Framer Motion
- Lenis

## Features

- Real-time 3D bronze sculpture with Three.js
- Animated liquid-metal GLSL shader background
- Drifting particle sparks
- Character-level text reveals synced to scroll
- Cinematic scroll-driven narrative
